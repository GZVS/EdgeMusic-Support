
# Edge Music Support

Need help with Edge Music for Mac? Have a question, found a bug, or want to suggest a feature?

Email **[GZVSDEV@ICLOUD.COM](mailto:GZVSDEV@ICLOUD.COM)**.

For technical issues, please include:

- Your macOS version and Edge Music version.
- A brief description of the problem.
- Steps to reproduce it and a screenshot, if possible.

For purchase or restore issues, describe what happens when you select **Restore Purchases**. Never send your Apple Account password or payment details.

Developed by Georgios Zacharidis.
